# 楽天Room 自動投稿システム（釣り・アウトドア特化）

このシステムは、楽天市場から釣り・アウトドア関連の商品を自動で検索・選定し、AI（OpenAI）を使って魅力的なキャプションを生成して、毎日自動で楽天Roomに投稿するプログラムです。

GitHub Actionsを使用しているため、**サーバー代不要・完全無料**で毎日自動運用が可能です。

## システムの特徴
- **季節に応じた商品選定**: 現在の月に合わせて「春のキャンプ」「冬のワカサギ釣り」など最適なキーワードで商品を検索します。
- **高評価商品の厳選**: レビュー件数と評価点数から独自のスコアリングを行い、本当に良い商品だけを投稿します。
- **AIによるキャプション生成**: 商品の魅力や季節感を取り入れ、ハッシュタグや絵文字を使った自然な紹介文を自動生成します。
- **URL掲載ルールの遵守**: 楽天Roomの規約（毎月25〜27日以外は夜のみURL掲載可）に自動で対応します。

## セットアップ手順

このプログラムをご自身のGitHubアカウントで動かすための手順です。

### 1. GitHubアカウントの作成（未作成の場合）
1. [GitHub](https://github.com/) にアクセスし、無料アカウントを作成します。

### 2. リポジトリの作成とコードのアップロード
1. GitHubにログインし、右上の「+」アイコンから「New repository」を選択します。
2. Repository nameに `rakuten-room-bot` など任意の名前を入力します。
3. **Private（非公開）** を選択し、「Create repository」をクリックします。
4. このフォルダ（`rakuten_room_bot`）の中身すべてを、作成したリポジトリにアップロード（Push）します。

### 3. シークレット（環境変数）の設定
プログラムが楽天やOpenAIに安全にアクセスできるよう、パスワードなどの機密情報をGitHubに登録します。

1. 作成したリポジトリの画面で、上部のタブから「**Settings**」をクリックします。
2. 左側メニューの「**Secrets and variables**」 > 「**Actions**」をクリックします。
3. 「**New repository secret**」ボタンをクリックし、以下の5つのシークレットを1つずつ登録します。

| Name（名前） | Secret（値） |
|---|---|
| `RAKUTEN_APP_ID` | 楽天WebサービスのアプリID（例: `7a27e617-7c74-4498...`） |
| `RAKUTEN_ACCESS_KEY` | 楽天Webサービスのアクセスキー（例: `pk_PtL70cgqXbGH...`） |
| `RAKUTEN_AFFILIATE_ID` | 楽天アフィリエイトID（例: `5391e7db.b3f9de18...`） |
| `RAKUTEN_EMAIL` | 楽天アカウントのログインメールアドレス |
| `RAKUTEN_PASSWORD` | 楽天アカウントのログインパスワード |
| `OPENAI_API_KEY` | OpenAIのAPIキー（`sk-...` から始まる文字列） |

> **注意**: OpenAI APIキーは[OpenAI Platform](https://platform.openai.com/api-keys)で取得し、少額（500円程度〜）のクレジットをチャージしておく必要があります。1回の投稿にかかるコストは約0.1円未満です。

### 4. GitHub Actionsの有効化
1. リポジトリの上部タブから「**Actions**」をクリックします。
2. 「I understand my workflows, go ahead and enable them」という緑色のボタンが表示されたらクリックして有効化します。

### 5. 動作テスト（手動実行）
1. 「Actions」タブの左側メニューから「**楽天Room 自動投稿**」をクリックします。
2. 右側に表示される「**Run workflow**」ボタンをクリックし、さらに緑色の「Run workflow」ボタンを押します。
3. 数十秒待つとジョブが開始されます。緑色のチェックマーク（✅）がつけば成功です。ご自身の楽天Roomを確認して、商品が投稿されているか確認してください。

## 運用について

### 投稿スケジュール
初期設定では、**毎日 20:00（日本時間）** に自動で実行されるように設定されています。
時間を変更したい場合は、`.github/workflows/auto_post.yml` ファイルの以下の部分を変更してください。

```yaml
  schedule:
    # 毎日 20:00 JST (= 11:00 UTC) に実行
    - cron: '0 11 * * *'
```
※ `cron` はUTC（協定世界時）で指定するため、日本時間からマイナス9時間した時間を設定します。（例: 日本時間の12:00にしたい場合は `0 3 * * *` とします）

### エラーが起きた場合
万が一、楽天のログイン画面の変更などでエラーが起きた場合は、GitHub Actionsの実行ログの「Artifacts」にエラー時のスクリーンショット（`debug_*.png`）が保存されます。これをダウンロードして原因を確認できます。
